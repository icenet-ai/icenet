# Installation

## Stable release

To install IceNet, run this command in your terminal:

``` console
$ pip install icenet
```

This is the preferred method to install IceNet, as it will always
install the most recent stable release.

If you don\'t have [pip](https://pip.pypa.io) installed, this [Python
installation
guide](http://docs.python-guide.org/en/latest/starting/installation/)
can guide you through the process.

## From sources

The sources for IceNet can be downloaded from the [Github
repo](https://github.com/icenet-ai/icenet).

You can either clone the public repository:

``` console
$ git clone git://github.com/icenet-ai/icenet
```

Or download the
[tarball](https://github.com/icenet-ai/icenet/tarball/master):

``` console
$ curl -OJL https://github.com/icenet-ai/icenet/tarball/master
```

Once you have a copy of the source, you can install it with:

``` console
$ python setup.py install
```
